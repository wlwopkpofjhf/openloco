## 🕹️ Overview

OpenLoco is an open-source recreation of Locomotion (2004) that runs the original game data on modern systems and enables community enhancements and modding.

Whether you're a newcomer or a veteran, OpenLoco provides the tools you need to get the most out of your gaming tools experience. Designed for Windows and macOS, it delivers a seamless, high-performance workflow.

---

## ✨ Key Features

| Feature | Description |
|---|---|
| **Original Data** | Runs original Locomotion assets and scenarios without modification |
| **High Resolution** | Supports resolutions beyond the original 800x600 limit |
| **Scenario Editor** | Build and share custom transport challenge scenarios |
| **Modding API** | Scriptable hooks for community content and game modifications |
